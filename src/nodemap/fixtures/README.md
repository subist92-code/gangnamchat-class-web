# 픽스처 번들 — 테스트 전용

`nodemap.bundle.fixture.json` 은 **테스트 전용**이다. 앱 화면·선생 폴더에 절대 쓰지 않는다.

- ID 접두 `X` · 이름은 「픽스처_…」 · `version: "fixture"`.
- `class.json.nodemap.version` 이 `fixture` 이면 문항 저장 버튼이 비활성된다(지시서 자리 A).
- 실제 번들은 `src/nodemap/nodemap.bundle.<course>.json` — 문서 리포
  `gangnamchat-class/docs/정본스냅샷/` 의 SNAP 사본이며 **편집 금지**(H-4).
